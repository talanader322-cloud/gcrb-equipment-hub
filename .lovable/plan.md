# إصلاح زر "استيراد الكل" في كتب كوماتسو

## سبب المشكلة (مؤكد من الكود)

المسح وجد 7891 كتاباً بنجاح، لكن حقل التصفية يقارن نص البحث برقم الكتاب فقط
(`b.book.includes(filter)`) — وقائمة الكتب لا تحتوي أي عنوان أو موديل، فقط
`{ book, dir }`. لذلك عند كتابة `D155-1` تصبح نتيجة التصفية صفراً، تظهر رسالة
"لا توجد كتب تطابق التصفية"، ويصبح زر "استيراد الكل" معطّلاً (شرط
`filtered.length === 0`). عنوان الحقل يقول "برقم الكتاب أو العنوان" وهذا وعد
غير منفَّذ حالياً.

## الحل

### 1) تعريف الكتب بأسمائها (حل السبب الجذري)

- بعد المسح، يُجلب أول ملف JSON لكل كتاب لاستخراج العنوان/الموديل
  (`BookName` / `BookInfo` / `BookSection`) بتوازٍ محدود (~8 طلبات) وشريط تقدم
  وإمكانية الإيقاف.
- تُخزَّن النتائج محلياً (localStorage) بمفتاح رقم الكتاب حتى لا يتكرر الجلب
  في كل زيارة.
- تصبح التصفية على: رقم الكتاب + العنوان + الموديل، مع تطبيع النص
  (`D155-1` = `D1551` = `d155 1`) حتى تعمل كتابة الموديل كما يتوقع المستخدم.
- يظهر عمود "العنوان/الموديل" في جدول الكتب.

### 2) توضيح حالة الزر بدل تعطيله بصمت

- عند وجود نص تصفية بلا نتائج: رسالة صريحة "لا يوجد كتاب مطابق لـ D155-1 —
  جرّب المسح بالأسماء أو رقم الكتاب" مع زر "استيراد كل الكتب الممسوحة".
- إذا كان التعطيل لسبب آخر (ليس مدير كتالوج، أو كوماتسو غير موجود في
  المصنّعين، أو لم يتم المسح بعد) تُعرض العبارة الموضِّحة تحت الزر مباشرة،
  بدل زر معطّل بلا تفسير.

### 3) استيراد موجّه للموديل

- زر "استيراد نتائج البحث" يستورد الكتب المطابقة فقط، مع سجل يوضح كل كتاب
  يُتخطّى وسببه (يستفيد من منطق `matchesAnyModel` الموجود).

## تفاصيل تقنية

- `src/lib/komatsuBooks.ts`: إضافة `resolveBookTitles(refs, { concurrency, signal, onProgress })`
  تعيد `Map<book, { title, text }>`، مع كاش، وإعادة استخدام `bookTitleFrom` /
  `bookTextFrom` / `listKomatsuPages` الموجودة. لا تغيير في الـ RPCs.
- `src/components/komatsu/KomatsuBooksImporter.tsx`: حالة العناوين، تصفية
  مطبَّعة على الرقم + العنوان، عمود جديد، ورسائل حالة الزر.
- `src/lib/translations.ts`: مفاتيح ثنائية اللغة للأزرار والرسائل الجديدة.
- لا تغييرات على قاعدة البيانات.
