# صور المعدات — استخراج تلقائي من الكاتلوج + رفع يدوي احتياطي

الهدف: لكل موديل معدة (45 موديل كوماتسو) صورة واضحة في قائمة المعدات وصفحة الموديل ونتائج البحث — تُستخرج تلقائيًا من الكاتلوج نفسه عند توفره، وتُرفع يدويًا إذا لم يتوفر.

## 1) المصدر التلقائي (الأساسي)

عند أرشفة أو استيراد كاتلوج للموديل، يقترح النظام صورة الموديل تلقائيًا من الكتاب نفسه:

- كتب كوماتسو المستوردة: صور المخططات محفوظة أصلًا في `catalog_schemes` (`image_url` / `image_storage_path`). النظام يعرض شريط مصغّرات لأول صفحات المخططات ويقترح المرشّح الأفضل (عادة صفحة الغلاف/الصفحة الأولى، مع تفضيل الصورة التي تحمل عنوانًا يشبه العرض العام للمعدة).
- كاتلوجات PDF المرفوعة: تُرسم الصفحة الأولى (والغلاف الداخلي) كصورة داخل المتصفح بنفس محرّك PDF المستخدم حاليًا في `pdfAnalysisService`، وتُحفظ كمرشّح للصورة.
- المرشّحون يظهرون في شاشة «صورة الموديل»: النظام يختار المرشّح الأول تلقائيًا، وللمدير زر «اعتماد» أو اختيار مصغّرة أخرى، أو «تخطّي».
- وضع اعتماد جماعي: زر واحد يعتمد المرشّح المقترح لكل الموديلات التي لديها كاتلوج ولا صورة لها.

الصورة المعتمدة تُنسخ إلى مسار خاص بالموديل داخل المخزن الخاص، فلا تتأثر لو حُدِّث الكاتلوج أو حُذف مخطط.

## 2) الرفع اليدوي (احتياطي، لِما لا كاتلوج له)

- زر «رفع صورة الموديل» في صفحة الموديل لمن يملك صلاحية إدارة الكاتلوج.
- رفع جماعي بالسحب والإفلات في صفحة الإدارة: مطابقة اسم الملف باسم الموديل أو مرادفه (`D155A-1.jpg` → الموديل، `DRP150-1,2.jpg` أو `D155-1.jpg` عبر المرادفات)، وما لا يُطابق يظهر بقائمة اختيار يدوية.
- الصور التي تنزّلها أنت من الإنترنت تُرفع بهذه الطريقة.

## 3) العرض

- الصور تُقدَّم دائمًا عبر روابط موقّعة قصيرة العمر من المخزن الخاص (لا رابط عام دائم)، بتحميل مؤجل.
- الموديل بلا صورة يظهر بأيقونة نوع المعدة (بلدوزر/لودر/حفارة/جريدر/مولد…) بهوية الأسود والأصفر بدل مربع فارغ.
- العرض في: قائمة المعدات، صفحة الموديل، بطاقة المعدة، ونتائج البحث.

## 4) النطاق التقني

- ترحيل صغير: `machine_models.image_path` (مسار داخل المخزن الخاص) + `image_source` (`catalog_page` / `scheme` / `manual`) للتوثيق؛ `image_url` يبقى كما هو للتوافق. لا مساس بأي جدول آخر.
- سياسات التخزين: كتابة في `models/<model_id>/...` داخل `machine-images` لمن يجتاز `can_manage_catalog`، وقراءة موقّعة للمصادَقين.
- `catalogRepository`: `listModelImageCandidates(modelId)` (مخططات الكاتلوجات المرتبطة + صفحات PDF)، و`setModelImageFromCandidate`، و`uploadModelPhoto` بنفس ترتيب العمل المعتمد: تحقق → رفع → تحديث السجل → حذف القديم / تنظيف عند الفشل، بحد 5MB وتحقق البصمة الحقيقية (JPEG/PNG/WebP).
- `pdfAnalysisService`: إضافة `renderPageImage(bytes, pageNumber)` لاستخراج صورة الصفحة الأولى، مع تدهور آمن إذا تعذّر تحميل المحرّك.
- مكوّنات جديدة: `ModelPhoto` (عرض + أيقونة بديلة)، `ModelImagePicker` (مصغّرات المرشّحين + اعتماد)، `ModelPhotoBulkUpload` (رفع جماعي بمطابقة الأسماء).
- تحديث `models.$modelId.tsx`، `equipment.tsx`، بطاقة المعدة، ونتائج البحث لعرض `image_path` أولًا ثم `image_url`.
- مفاتيح ترجمة عربية/إنجليزية لكل نص جديد.

## 5) الترتيب

1. الترحيل + سياسات التخزين + `ModelPhoto` والأيقونات البديلة (يُصلح الشكل فورًا).
2. المرشّحون من مخططات الكاتلوجات + شاشة الاعتماد + الاعتماد الجماعي.
3. استخراج صفحة غلاف PDF كمرشّح.
4. الرفع اليدوي الفردي والجماعي.

## غير مشمول

- أي بحث أو جلب تلقائي لصور من الإنترنت.
- تغيير منطق البحث أو المخططات التفجيرية.
